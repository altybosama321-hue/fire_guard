# FireGuard 🛡️🔥

**FireGuard** هو تطبيق دقيق وذكي لنظام كشف ومكافحة الحرائق التلقائي، مدمج مع حواسات إنذار ونظام رصد فوري عبر **Firebase Realtime Database**.

---

## 📱 مميزات التطبيق (Features)
- **لوحة تحكم فورية (Live Dashboard):** متابعة قراءات مستشعرات الحريق والغاز والدخان لحظة بلحظة.
- **التحكم التلقائي واليدوي (Auto & Manual Control):** إمكانية التبديل بين النظام التلقائي والتحكم اليدوي لمضخة المياه وجرس الإنذار.
- **التنبيهات والإشعارات (Smart Alerts):** نظام تتبع حوادث مستشعرات الحريق مع فلترة سريعة.
- **متابعة حالة الأجهزة (Device Status):** فحص اتصال وحدة ESP32 وخوادم Firebase.
- **مصادقة آمنة (Authentication):** تسجيل الدخول وإنشاء حسابات عبر Firebase Auth.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **الإطار البرمجي (Framework):** Flutter (Dart)
- **قواعد البيانات (Database):** Firebase Realtime Database
- **المصادقة (Auth):** Firebase Authentication
- **التصميم (UI/UX):** Material Design 3

---

## 🚀 طريقة تشغيل المشروع محلياً (How to Run)

1. **استنسخ المستودع (Clone Repository):**
   ```bash
   git clone https://github.com/altybosama321-hue/fire_guard.git
   cd fire_guard
   ```

2. **ثبّت الحزم والاعتمادات (Install Dependencies):**
   ```bash
   flutter pub get
   ```

3. **شغّل التطبيق (Run Application):**
   ```bash
   flutter run
   ```
